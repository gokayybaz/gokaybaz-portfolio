# Personal SEO and GEO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert the current bilingual React portfolio into a Turkish-first, crawlable personal expertise site that helps hiring managers discover and verify Gökay Baz as a BT infrastructure, IT/OT and DevOps/platform specialist.

**Architecture:** Replace hash-based public routing with browser URLs, keep the existing JSON content store as the source of truth, and add a typed content model for expertise pages and articles. Share a pure SEO metadata/schema builder between client head updates and Express-generated HTML, sitemap, robots and `llms.txt` responses.

**Tech Stack:** React 19, React Router 8, Vite 8, Express 5, TypeScript 6, Zod 4, React Markdown, Vitest, Tailwind CSS 4.

**Spec:** `docs/superpowers/specs/2026-09-12-seo-geo-design.md`

## Global Constraints

- Türkiye is the primary market; Turkish is the canonical language and English is served under `/en/`.
- The primary role is **BT Altyapı / Sistem Uzmanı**, followed by **IT/OT ve Üretim Dijitalleşmesi Uzmanı** and **DevOps / Platform Engineer**.
- Position the profile as **Uzman / tek kişilik BT sorumlusu** without unsupported seniority claims.
- The site must expose the person, work history, education, projects and social profiles as one consistent entity.
- Content must follow `sorun -> yaklaşım -> uygulama -> sonuç` and use real project evidence and metrics.
- Sensitive production data, network topology and security configuration must not be published.
- `llms.txt` is a supporting resource, never a replacement for crawlable HTML, JSON-LD or original content.
- Keep existing admin authentication and JSON persistence behavior intact.
- Use ASCII for code identifiers and URLs; Turkish copy may use the existing UTF-8 project convention.
- Do not add fake backlinks, keyword stuffing, schema spam or AI-generated high-volume filler content.
- Do not claim guaranteed Google or AI rankings.
